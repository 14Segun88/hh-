## 💡 Архитектура и концепция

### Почему существующие решения устарели?
Репозитории вроде `VictoriaFirsova/JobSearch`, `MarselDav/HH-Job-Assistant`, `shizzka/job-hunter`, `littleonepiggy/python-hh` опирались либо на устаревший публичный REST API (в котором отклики для обычных соискателей отключены/ограничены), либо на примитивные HTTP-запросы, моментально блокируемые защитой Cloudflare / Qrator на hh.ru.

### Решение: Playwright Persistent Context + Двухконтурный LLM Harness
1. **Эмуляция человека с постоянной сессией (`BrowserHarness`)**:
   - Запуск через Playwright с сохранением постоянного профиля браузера (`data/browser_profile`).
   - Вы авторизуетесь один раз командой `python main.py login` (через SMS, пароль или Госуслуги). Cookies и сессия сохраняются навсегда.
   - Скрыты признаки автоматизации (`navigator.webdriver`), используются человекоподобные задержки и прокрутка.

2. **Двухконтурный стек моделей (Local Qwen + NVIDIA NIM)**:

| Задача | Tier 1: Локальная Qwen 2.5 7B (LM Studio) | Tier 2: Облачная NVIDIA NIM (Llama 70B / Nemotron / R1) |
|---|---|---|
| **Анализ вакансий** | Мгновенный отсев по стоп-словам, извлечение зарплатной вилки, стека, красных флагов, базовый скоринг (0–100) | Глубокое досье компании, анализ рисков, сравнение ЗП с рынком, стратегия на интервью и финальный вердикт (только при балле >= 70) |
| **Переписка и чаты** | Классификация входящих (приглашение, вопрос, отказ, спам), извлечение предложенных дат/вопросов | Черновики ответов: выверенный деловой русский, четкая позиция по зарплате и удобным слотам |
| **Тесты и анкеты** | Разбор структуры формы, автоподстановка фактов из резюме (опыт, гражданство, локация, график) | Развернутые ответы на открытые и сложные технические вопросы от первого лица инженера |

3. **Режим работы без круглосуточного VPS**:
   - Агент рассчитан на запуск на 2–3 часа в день (утренний или вечерний слот).
   - Скользящее окно **48 часов**: обрабатывает данные за *вчера + сегодня*.
   - Полная сводка и карточки топ-вакансий отправляются в **Telegram**.

## 🛠 Требования к оборудованию

- **ОЗУ**: 15–16 ГБ RAM.
- **GPU**: 4 ГБ VRAM (например, GTX 1650/1050 Ti или мобильная графика).
- **Локальный рантайм**: LM Studio с загруженной моделью `Qwen 2.5 7B Instruct` (квантование `Q4_K_M` или `Q3_K_M`, часть слоев выгружается в VRAM, остальное в RAM).
- **Ключ NVIDIA NIM**: бесплатный или платный API ключ с [build.nvidia.com](https://build.nvidia.com/).

## 🚀 Быстрый старт

### 1. Установка окружения

```bash
# Клонируйте проект и перейдите в папку
cd /home/segun/CascadeProjects/hh.ru

# Активируйте виртуальное окружение
source .venv/bin/activate

# Если создаете заново:
# pip install -r requirements.txt
# playwright install chromium
```

### 2. Настройка конфигурации

Скопируйте пример файла переменных окружения:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```ini
# Локальная модель в LM Studio
LM_STUDIO_URL=http://localhost:1234/v1
LM_STUDIO_MODEL=qwen2.5-7b-instruct

# NVIDIA NIM (Llama 3.3 70B или Nemotron)
NVIDIA_API_KEY=nvapi-your-key-here
NVIDIA_MODEL=meta/llama-3.3-70b-instruct

# Telegram (по желанию, для получения сводки)
TELEGRAM_BOT_TOKEN=123456789:ABCdef...
TELEGRAM_CHAT_ID=123456789

# Режим откликов: semi_auto (собирает топ в дайджест) или auto (откликается сам)
APPLICATION_MODE=semi_auto
```

### 3. Заполнение профиля и правил поиска

1. **`config/candidate_profile.yaml`**: укажите ваше имя, опыт, стек, зарплатные ожидания и факты для анкет (уровень английского, локация и т.д.).
2. **`config/search_rules.yaml`**: задайте поисковые фразы (`Python Senior`, `FastAPI`), стоп-слова (моментальный отсев нерелевантного) и фразы-триггеры красных флагов.

## 💻 Команды CLI

### Проверка связи с нейросетями
```bash
python main.py test-llm
```
*Проверяет доступность локального LM Studio (порт 1234) и NVIDIA NIM.*

### Однократная авторизация на hh.ru
```bash
python main.py login
```
*Откроет окно браузера Chromium. Вы входите в свой личный кабинет hh.ru привычным способом (SMS / пароль / Госуслуги). Сессия надежно сохраняется в локальной папке `data/browser_profile/`.*

### Запуск сессии поиска и обработки (вчера + сегодня)
```bash
python main.py run
```
Опции:
- `--mode auto` — автоматически отправлять отклик и сгенерированное письмо для вакансий с баллом >= 70.
- `--mode semi_auto` (по умолчанию) — сформировать досье и черновики, прислать на подтверждение.
- `--max-vacancies 30` — ограничить число вакансий за сессию.

### Просмотр базы найденных вакансий
```bash
python main.py vacancies --min-score 70
```

### 🚀 Боевой визуальный режим (Live Visual Runner)
```bash
python main.py live --limit 3 --pool-size 35
```
*Запускает полный автономный цикл в видимом окне Chromium с HUD-индикатором: переписка в чатах, отбор 35 вакансий, автоподача 3 целевых откликов, сканирование Telegram-каналов и онлайн-синхронизация воронки.*

### ✈️ Охота за вакансиями в Telegram-каналах (без API-ключей)
```bash
python main.py tg --days 1
```
*Автономный сбор и скоринг AI/LLM вакансий за сегодня из каналов `@careerspace`, `@datasciencejobs`, `@Getitrussia`, `@it_hr_vacancy` через официальные веб-зеркала. Определяет способ связи (личка `@username`, форма, сайт), формирует авторский питч и отправляет интерактивные карточки в Telegram CRM.*

### 🏢 Запуск Telegram CRM-бота (Битрикс24)
```bash
python main.py bot
```
*Запускает интерактивного бота в Telegram для мониторинга воронки сделок, статусов интервью и одобрения откликов.*

### Отправка дайджеста в Telegram
```bash
python main.py digest
```

## 🗄 Хранение данных

Все данные хранятся локально в базе данных SQLite: `data/hh_agent.sqlite3`.
- `vacancies` — база найденных вакансий со скорингом, выделенным стеком, рисками, досье и статусами (`NEW`, `SKIPPED`, `DOSSIER_READY`, `APPLIED`).
- `negotiations` — история входящих сообщений от работодателей с классификацией и подготовленными черновиками ответов.
- `questionnaires` — сохраненные вопросы и ответы анкет работодателей.

## 🔒 Безопасность

- Все SQL-запросы используют строгую параметризацию через `aiosqlite` без конкатенации строк.
- Секреты хранятся только в `.env` и добавлены в `.gitignore`.
- Браузерный профиль изолирован в локальной директории `data/browser_profile/`.
