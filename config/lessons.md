## Сопроводительные письма (AI / LLM / Agentic Engineer)
- **Фокус на реальных проектах и GitHub**: Обязательно давать ссылки на профиль GitHub (`14Segun88`) и ключевые репозитории: `moge-document-expertise-ai` (мульти-агентная система на 8 агентов для госэкспертизы), `pd-document-analyzer` (CoT-экстракция из PDF) и `news-predictor-ai` (PyTorch Fusion Network + CatBoost + Embeddings).
- **Оцифрованные результаты (Metrics)**: Работодатели отлично конвертируют кандидатов, указывающих реальные метрики: сокращение времени рутинного анализа с 12–42 дней до 5–10 минут, 100% accuracy на CoT-верификации с Knowledge Base.
- **Практический опыт с инференсом**: Подчеркивать умение работать как с локальными квантованными моделями (LM Studio, GGUF, Mistral, Qwen), так и с высокопроизводительными API (NVIDIA NIM, Groq Cloud, OpenAI).
- **Никаких общих фраз**: Не писать «Я увлечен развитием искусственного интеллекта». Сразу переходить к стеку: Multi-Agent Systems, RAG (Weaviate), CoT Reasoning, FastAPI, Playwright.
- **Объем письма**: 2–3 емких абзаца (100–120 слов).
